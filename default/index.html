Default receiver audio test

Select Default for testing in the Studio Cast dialog, then choose a Chromecast device.

This route launches Google's built-in Default Media Receiver (CC1AD845) and loads the authenticated audio stream. Google owns the TV receiver page. This project page describes the isolated test and does not replace Google's application.

  • Audio-only baseline: no Studio GUI, screen capture, or WebRTC video.
  • Verify device connection, audio start, pause, resume, volume, and stop.
